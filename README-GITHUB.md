# OrbitConvert

A lightweight, local macOS file converter with a radial format picker.

![OrbitConvert icon](Assets/AppIcon.png)

## Features

- Hold the configured shortcut and drag a Finder file to a format sector;
  release to convert. A menu-bar command is also available.
- Same-type batch conversion. Multiple supported images selected as PDF merge
  into one document in natural filename order.
- Native DOCX, PPTX and XLSX conversion without an installed Office suite.
- PDF text-layer extraction with OCR fallback, image-to-editable-DOCX OCR,
  and common image formats, including HEIC and WebP.
- TXT and supported Office documents can render to PDF and all supported raster
  targets. Image-to-TXT is not offered; the existing image-to-DOCX route is retained.
- Live drop previews, centered five-column candidate rows, smooth hover transitions,
  and optional system trackpad feedback patterns (not physical amplitude control).
- Local RAR4/RAR5 extraction with a bundled UnRAR engine and password prompt.
  Single top-level items are published directly; multiple items get a new folder.
  Existing files are never overwritten.
- Customizable glass color, wheel size, text sizes, output names and shortcut.
- An offline third-party-license viewer in settings.
- System RAW/DNG decoding to photos (camera support depends on macOS; actual
  camera-file rendering is not yet validated in the restricted test environment).
- RAR extraction through the radial picker; optional first-launch default-app setup.
- Collapsible source categories and right-click target management across either
  all supported sources or only the current category.
- Top navigation for General, Features and Open-source Licenses; per-source
  wheel targets can be added, removed and reordered by dragging in the preview.
- Advanced settings separate Apple-app assistance, whitespace cropping and
  filename templates. Drag a sector into the editor's outer blank/removal area
  to remove it. Larger clear Liquid Glass cards expose all supported targets.
- Raster formats PNG/JPEG/WebP/HEIC/GIF/BMP/TIFF support cross-conversion;
  defaults remain unchanged. SVG is rasterized, not generated by vector tracing.
- Optional AirDrop wheel action shares original files through the system UI;
  the user chooses the recipient. No intermediate conversion or copy is created.

## Boundaries

Office layout is approximate, not a replacement for Microsoft Office's renderer.
PPTX charts/SmartArt/animations and full Excel styles/charts are not reproduced.
XLSX formulas use cached values and are not recalculated. Legacy XLS is unsupported.
Only Apple-native .pages/.numbers/.key exports may automate installed iWork apps,
after an explicit setting is enabled. These exports may display a temporary window.

RAR passwords are requested only when needed and are not saved. Multi-volume
archives and links remain unsupported. Batch selection
is limited to 500 same-type files; merged PDFs are limited to 2,000 pages.
Outputs are saved beside their sources; merged PDFs go beside the first sorted
input. Successful batch items are kept even if another item fails.

HEIC batch conversion has been confirmed by the project owner on their Mac.
The automated test environment cannot decode HEIC pixels; failures there are
reported without publishing blank pages. Desktop compatibility still varies.

## Build and run

See [BUILDING.md](BUILDING.md). Packaging needs macOS, Xcode's macOS 26 SDK or
newer and WebP libraries. The current binary release process is ad-hoc signed,
not notarized or App Store approved. Apple Silicon is the tested architecture.

Finder interaction requests accessibility and automation permissions. Conversion
does not upload documents. Explicitly selecting AirDrop hands the selected files
to macOS for user-confirmed sharing. The project does not currently include analytics or
an automatic update service. A formal release privacy policy is still pending.
